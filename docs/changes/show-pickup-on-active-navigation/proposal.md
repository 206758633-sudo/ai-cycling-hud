# 骑行导航中短暂显示点单信息

## Why

骑士当前在车载屏显示导航时会拦截点单状态。骑行途中需要能看到点单信息，同时保持当前路线和导航播报。

## What Changes

- 点单受理、暂停、结算就绪和失败时，骑士向 C3 发送简明状态卡。卡片显示商品与已确认的必要信息。
- 有路线时，状态卡显示 3 秒，随后恢复最新的路线图、位置和转向。无路线时，状态卡保持可见，直到状态变化或导航开始。
- 导航期间语音继续播报转向、距离和到达状态。订单结果可以显示在屏幕上，其语音等待导航结束。

## Capabilities

### New Capabilities

- `pickup-on-active-navigation`：在车载导航中短暂展示点单状态，同时保持导航语音。

## Impact

涉及骑士点单状态、高德导航和 PANBOPO C3 的蓝牙显示协议。原小布 ESP32-S3 用当前聊天音色播报导航。
