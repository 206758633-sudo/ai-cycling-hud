# 导航和点单显示切换

## ADDED Requirements

### Requirement: 在路线期间显示点单卡

车载屏 SHALL 显示最新点单状态。有路线时显示 3 秒后回到当前导航，维持路线同步。

#### Scenario: 导航中收到新点单结果

- **WHEN** C3 正在显示导航，骑士推送一条新的点单状态
- **THEN** C3 显示该状态约 3 秒，随后恢复最新路线及转向，导航语音继续播报

#### Scenario: 当前没有路线

- **WHEN** C3 收到点单状态且没有活动路线
- **THEN** C3 保留该点单提示，直到新状态或路线到达
