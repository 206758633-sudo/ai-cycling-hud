# 设计

1. 为点单卡单独定义蓝牙消息。按订单 ID 和进度去重，接收确认后的商品、数量、金额或失败原因；缺少核验的字段保持空白。
2. C3 收到导航中的点单卡后计时 3 秒。卡片显示时，路线、位置和转向持续更新缓存。计时结束后显示最近一帧导航。连接断开则清除旧内容。及时显示导航结束、失联等状态。
3. 导航语音独立于显示状态。骑士把高德指引交给后台签名，再通过既有蓝牙链路发给原小布 ESP32-S3。小布使用当前聊天音色。指引去重并在短时有效期内播报。启动、结束和保活控制订单回执的播放优先级。
4. 导航期间的点单播报留在回执队列。切换屏幕显示不改变 GPS 路线、语音播放队列或订单执行状态。
5. 固件使用 UTC 校验回执有效期，屏幕时钟单独应用时区。骑士在反馈连接恢复后，可补发仍在有效期内的当前指引。
