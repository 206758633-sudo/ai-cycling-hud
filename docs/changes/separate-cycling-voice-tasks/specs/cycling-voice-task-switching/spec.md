# 小布按语音任务切换

## ADDED Requirements

### Requirement: 独立受理语音任务

小布 SHALL 按语音意图分别受理普通导航和点单，后台成功接受后立即返回受理状态，并用对应任务 ID 回报实际终态。

#### Scenario: 点单期间指示普通路线

- **WHEN** 美团操作正在执行，用户说「导航到广州天河区黄村地铁站 B 口」
- **THEN** 后台创建独立的普通导航任务，小布能接受下一条语音，骑士在可核对的操作点暂停订单并优先启动导航

### Requirement: 按原订单安全续办

骑士 SHALL 保留暂停订单的门店、规格和购物车证据，导航结束且手机可以执行时自动恢复。

#### Scenario: 导航结束后自动续办

- **WHEN** 导航结束，后台有原来暂停的订单
- **THEN** 骑士按原编号和规格继续执行，若已进入加购核对，则保留核对结果，付款仍由用户完成
