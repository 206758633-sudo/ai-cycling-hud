# 拆分小布语音受理、导航和点单

## Why

小布点单时会同步等美团回执，骑士又会在执行美团时停止领取导航。用户中途说「导航到某地」时，需要先结束点单才能继续，而当前小布的导航工具也只识别已核验的自提门店。

## What Changes

- 小布按意图发起普通导航、点单、订单续办或结果查询。后台记录受理后立即回话，实际结果继续使用小布当前音色播报。
- 导航和订单各有任务 ID、状态和回执。点单途中收到导航指令时，在美团安全操作点保留订单进度，优先启动核对过的路线。
- 导航期间继续接收语音点单。保存待办，导航结束后自动恢复。已开始加购时先完成该笔购物车核对再切换，付款仍由用户操作。

## Capabilities

### New Capabilities

- `cycling-voice-task-switching`：按语音意图独立受理普通导航及美团订单，并安全切换手机执行权。

## Impact

小布 ESP32-S3 的语音工具与回执，Mac 局域网服务，骑士 iOS 前台切换与美团进度恢复。沿用车载屏的高德路线同步。
