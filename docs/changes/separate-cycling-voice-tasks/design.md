# 设计

1. 小布注册普通导航工具，提取城市、区和目的地，提交到现有骑行任务接口。点单与导航都在服务端接受后返回受理信息。已受理、已开始、已到结算和失败分别回报真实状态。
2. 回执携带任务 ID 和状态。在板端等待可用的语音时机，再使用当前小布音色播报。先真机验证异步回执能进入现有语音会话，同时保留用户主动查询结果的入口。BLE 与 HTTP 的同一回执只播一次。
3. 骑士在现有美团背景执行窗口内检测新导航，协作暂停。只在当前点击已返回且状态可核验时切换前台。iOS 暂停骑士进程时，后台保留已受理任务。手机取得执行权后再发送启动结果。
4. 加购前保存已核对门店和原商品规格。已经开始加购时，由当前美团流程核对购物车后交还前台。结果不明时保留需核对状态。恢复时从安全入口重新核对门店、规格和数量，同一订单 ID 使用新租约，拒绝旧租约的迟到回执。
5. 导航优先。普通路线启动后，转向和路线图继续发给车载屏。导航结束后，后台将暂停订单按原编号转回待办，骑士自动续办。
