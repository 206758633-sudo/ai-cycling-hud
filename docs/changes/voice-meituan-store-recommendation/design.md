# 设计

1. 语音工具区分查店、比较评分、读菜单和实际点单。查店任务经签名蓝牙中继由骑士转发，保留城市、区、地标、出口和菜系，用任务编号去重。
2. 骑士领到只读任务后复用已核实的美团地址选择和截图读取。使用点评高分筛选，按实际展示的评分、距离及堂食信息核对候选。缺少可以核实的数据时反馈具体原因。
3. 从同一门店的菜单或商家推荐卡取最多三道有明确名称的菜。以现有订单卡数据格式将分店和菜传到 C3，记录小屏接收确认。
4. 按美团门店品牌、分店名和所在市区核对高德结果，必须唯一匹配。美团结果提供可核实的地址时，再核对地址。车载屏回执先到，用户另说「开始导航」才创建导航任务。
5. 在实际地址搜索页核对当前城市。控件树没有暴露城市时，读取画面上的城市标签。切换城市后等待搜索框回到屏幕内，重新输入地点，再按请求的市、区和出口核对结果。
