# 语音查找美团门店与小屏推荐

## Why

真机语音测试把「找烧烤店」发成了自提点单。骑士因此执行商品和自提地址核对，没有向小屏发送门店、评分或菜单。此前的小屏与导航验证来自骑士调试入口。

## What Changes

- 为查找附近餐厅、按评分推荐和查看特色菜设立独立的只读语音工具。
- 骑士定位语音中的搜索地点，在美团比较可核实候选的评分和距离，再把门店与三道可核实的菜传到小屏。
- 高德仅使用能核实为美团同一分店的名称或地址。小屏确认收到后，用户另说「开始导航」才启动。

## Impact

小布 MCP 工具、现有蓝牙中继、后台任务与骑士 iPhone 调试版。复用 C3 显示链路。查店流程不触发加购、结算和付款。
