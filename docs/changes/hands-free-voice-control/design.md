## Context

小布语音已经可向局域网服务发出自提任务，骑士 iPhone 自动领取。已有蓝牙回执和 Wi-Fi 文本回退。控屏页仍暴露表单、按钮和未接入的演示操作。

## Decisions

1. iOS 控屏使用真实语音自提任务作为状态源，页面在前台自动更新。既有浏览器演示入口保留。
2. 糖度不同时，iPhone 仅在加购前、已核实门店和对应商品的规格面板发结构化追问。用户明确接受「不额外加糖」后，服务端生成关联的续办任务，保留商品、数量、其余规格、预算、目的地与已核实分店。订单租约和新任务 ID 防止上一条蓝牙回执被再次使用。
3. 补规格期间骑士回到前台，留给语音回复继续；规格一致直接到结算页。播报结算状态并保留既有付款边界。
4. 小布工具对缺失信息先追问，直接使用实际回执。保留向设备重听或确认回执的入口，用户无需依赖骑士的手动表单。

## Validation

验证初始语音任务、规格追问、明确答复续办、拒绝错误选项、重复请求、旧版回执兼容和结算付款边界。真机工作以设备在场和本地自动化会话就绪为准。
