## Why

真机已验证骑士把黄村新天地店交接给高德路线预览。美团加购后规格弹层遮住结算按钮，手机未取得结算回执，也没有启动实际 GPS 骑行导航。用户要求无需再操作手机，并能确认最终进展。

## What Changes

- 验证规格弹层收起后再处理结算。区分已加购、待付款、失败和未知状态。
- 从骑士内置高德骑行 SDK 启动导航，使用 GPS 导航回调确认启动并驱动现有车载屏。
- 小布用现有聊天音色播报可核实的美团结果及导航结果。控屏展示相同状态。用户听完核实回执并明确说「开始导航」时才启动。

## Capabilities

### New Capabilities

- `pickup-voice-navigation`：自提结算回执、免手导航启动和结果确认。

### Modified Capabilities

## Impact

骑士 iOS、美团本机操作、现有高德导航控制器、订单服务及小布语音回执。沿用现有手机定位和轨迹授权以及用户付款流程。
