# 设计

1. 复用本地骑士服务及认证。普通骑行任务拥有独立 ID、目的地和有效期。手机仅在前台空闲时领取，按任务 ID 防重，避免替换当前导航。服务只在收到高德 GPS 成功回调后标记已启动。
2. 骑士按城市和地点搜索高德 POI。唯一核验后规划骑行路线，使用手机定位。目的地不唯一或缺少定位时返回原因，等待用户核对。
3. 骑士将高德路线投影、简化并量化成屏幕坐标。车载屏仅处理路径点和位置更新，不接入地图瓦片。蓝牙保留现有转向消息，新增带路线版本、帧序和超时的路线数据。重连时先同步当前路线，再恢复位置和转向。
4. 优先识别并验证已授权的 ROADLINK 车载屏。已有屏幕仍可收转向。新屏对路线更新做完整性校验，断线或路线终止时清除旧图。验收期间使用真机静止定位。
5. 骑士为同一路线发送保活。车载屏将保活与 GPS 位置分开处理。缺少新位置时保留最近一次得到的位置，过期的转向指令独立清除。保活停止或蓝牙断开后清除路线。
