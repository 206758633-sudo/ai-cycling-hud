# 设计

1. 小布复用现有点单和导航参数。签名覆盖任务类型、请求正文和有效期。通过当前反馈服务增加上行特征值，骑士订阅后接收分片。
2. 骑士以手机凭据访问固定的中继接口。后台验证小布签名、有效期和任务类型，再使用现有的校验、排队和幂等逻辑。
3. 骑士将已确认的受理结果发回小布。遇到断线或未取得受理结果时，使用相同请求编号走现有 Wi-Fi 接口或按明确失败反馈。
4. 验收顺序依次为小布提交、骑士转发、后台入库、骑士领取、小布收到受理。真机测试确认 Mac 保留当前网络。
5. 升级固件后，小布在旧反馈通道握手时提示 iOS 刷新蓝牙服务表。骑士发现链路超时后重试，订阅新版任务上行。
