## ADDED Requirements

### Requirement: 跨网段受理语音任务

骑士 SHALL 通过现有加密蓝牙连接接收小布发出的点单或普通导航请求，并将经验证的请求交给原有后台任务队列。

#### Scenario: 蓝牙可用且设备分属两个局域网

- **WHEN** 小布发出有效的点单或普通导航请求
- **THEN** 骑士转发并把后台确认的受理状态回给小布

#### Scenario: 受理回包丢失后重试

- **WHEN** 同一个请求编号经蓝牙或 Wi-Fi 重试
- **THEN** 后台返回已有任务编号，队列仅含一笔对应任务

#### Scenario: 签名失效或负载过期

- **WHEN** 后台收到不能验证的中继包
- **THEN** 后台拒绝创建任务

#### Scenario: 用户说开始导航到自提门店

- **WHEN** 小布已播报实际美团自提结算，用户明确要求开始导航
- **THEN** 骑士经蓝牙中继接收请求，后台核对当笔有效结算，骑士用其中的实际门店地址启动高德
