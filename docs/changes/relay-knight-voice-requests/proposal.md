# 跨网络发送骑士语音任务

## Why

小布通过本地 Wi-Fi 直接调用骑士后台。当小布连 MIFI、骑士和 Mac 连另一网络时，小布仍可与语音云对话，但发单接口无法访问，骑士持续轮询也领不到任务。

## What Changes

- 拟复用小布和骑士已有的加密蓝牙连接，将点单和普通导航请求从小布交给骑士。
- 骑士将请求转发至现有后台，取得受理结果后回传小布。后台继续负责去重和排队，由骑士本机执行任务。
- 保留现有同网直连能力，使用同一请求编号防止重试产生重复任务。

## Capabilities

### New Capabilities

- `voice-request-relay`：在小布和后台位于不同局域网时发送骑士任务。

## Impact

涉及小布 ESP32-S3、骑士 iPhone 调试版和 Mac 后台。中继覆盖点单、普通导航及已核实的美团自提门店导航。用户已确认复用蓝牙转发。
